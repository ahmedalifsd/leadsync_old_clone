🚀 QUICK START IN 3 STEPS:

1. Run Setup Script:
   $ ./start-dev.sh

2. Start Backend (Terminal 1):
   $ cd backend
   $ source venv/bin/activate
   $ python manage.py runserver 0.0.0.0:8000

3. Start Frontend (Terminal 2):
   $ cd frontend
   $ npm run dev

   Backend: http://localhost:8000
   Frontend: http://localhost:5173
